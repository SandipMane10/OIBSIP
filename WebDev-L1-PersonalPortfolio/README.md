## Personal Portfolio Website

A modern and responsive Personal Portfolio Website developed as part of the OIBSIP Web Development Internship. The portfolio is designed to present my professional profile, technical skills, achievements, projects, and contact information through a clean and interactive web interface.

## Project Overview

This portfolio website provides a professional online presence where visitors can learn about my background, technical knowledge, projects, achievements, and career objectives.

The website includes dedicated sections for Home, About, Technical Skills, Projects, and Contact, along with links to my professional and social profiles.

## Key Features
🏠 Home Section – Introduction and professional profile
👨‍💻 About Me – Academic background, achievements, experience, and career objective
🛠️ Technical Skills – Programming, frontend, database, and computer science concepts
📂 Projects Section – Showcase of completed projects
📞 Contact Section – Contact details and message form
🔗 Social Media Integration – Instagram, LinkedIn, and GitHub links
📱 Responsive Design – Designed to provide a good experience across different screen sizes
🎨 Modern UI – Clean layout with interactive elements and attractive styling

## Technologies Used
HTML5 – Website structure and content
CSS3 – Styling, layout, responsiveness, and visual design
Font Awesome – Social media and interface icons
